Method
01

Start at the P&L, not the dashboard

Every question gets traced back to a line someone owns. If an analysis can't move a number on that line, it isn't worth running.

02

Separate the driver from the noise

Margin problems arrive with three plausible causes wearing each other's clothes. The work is isolating which one actually moved, then proving it.

03

Numbers tie out, first time

An analysis that needs a correction the next morning costs more credibility than it ever bought. I reconcile before I present.

04

Automate anything recurring

If I've pulled it twice by hand, it becomes a pipeline. The time saved goes back into questions nobody has asked yet.
